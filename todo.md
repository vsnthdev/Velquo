# Velquo — Remaining KDE Connect Features

- [x] **Remote File Browser (SFTP)** — Browse phone folders and storage over SFTP (`kdeconnect.sftp`)
- [x] **System Volume Control** — Expose and control Mac system audio volume from the phone (`CoreAudio` / `kdeconnect.mpris`)
- [x] **Run Commands** — Trigger pre-configured shell commands between Mac and phone (`kdeconnect.runcommand`)
- [x] **Notifications Sync** — View and dismiss phone notifications on Mac (`kdeconnect.notification`)
- [x] **OTP / 2FA Auto-Copy** — Extract and copy verification codes from incoming notifications
- [x] **Find My Phone / Mac** — Ring the remote phone at full volume or ring this Mac (`kdeconnect.findmyphone.request`)
- [x] **Presentation Remote** — Control slides and laser pointer from phone (`kdeconnect.presenter`)
- [x] **Remote Input (Touchpad & Keyboard)** — Use phone as Mac trackpad/keyboard (`kdeconnect.mousepad.*`)
- [x] **Device Settings & Preferences** — Unpair, custom download folder, per-plugin toggles, and Launch at Login
- [x] **Clipboard Sync** — Auto-sync copied text between Mac and phone (`kdeconnect.clipboard`)
- [x] **Auto-Pause Media on Calls** — Pause Mac media playback automatically during phone calls
- [x] **Control Mac Media from Phone** — Expose Mac Now Playing and media controls to the phone (`kdeconnect.mpris`)
- [x] **Share URLs & Text from Mac** — Send links and text snippets from Mac to phone (`kdeconnect.share.request`)
- [x] **Multi-File Batch Upload Queue** — Sequential multi-file upload progress (`kdeconnect.share.request.update`)
- [x] **Mac Battery Reporting** — Send MacBook battery & charging status to the phone (`kdeconnect.battery`)
- [x] **Ping Notifications** — Show native macOS & in-app notification when receiving a ping from a device (`kdeconnect.ping`)
